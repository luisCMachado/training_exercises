## Começa aqui

1. No GitHub, usa **Code → Download ZIP**. Se já recebeste o ZIP, extrai-o antes de abrir os ficheiros.
2. Abre o `index.html` da pasta principal no navegador e escolhe o primeiro código que o formador te atribuiu.
3. Lê o quadro **Medidas desta ficha**, logo a seguir ao objetivo. Distingue as medidas a usar e os pontos de mudança das três larguras de teste. Abre o `style.css` da ficha para começares a etapa 1; no fim desse ficheiro tens as medidas para consulta.
4. Para perceberes que elementos estás a selecionar, abre o `index.html` da ficha no editor e procura o comentário **INÍCIO DO EXERCÍCIO**. Só precisas de alterar o HTML quando uma etapa o disser.
5. Quando o enunciado diz **16 px**, escreve `16px` no CSS, sem espaço. Guarda o CSS e atualiza a página. Compara o resultado com o esquema; no fim, faz os testes a 390, 768 e 1100 px e preenche `registo.md`.
6. Repete para a segunda ficha e entrega as tuas duas pastas. Não precisas de instalar nada nem de abrir um servidor.

## Os cinco ficheiros de cada ficha

- `index.html` — página, esquema do objetivo, etapas e testes.
- `style.css` — o ficheiro em que vais escrever.
- `base.css` — cores, tipos de letra e apresentação de partida. Já está pronto.
- `objetivo.svg` — esquema que se pode abrir na ficha HTML.
- `registo.md` — as tuas previsões e os resultados dos testes.

Se o formador propuser uma síntese de grupo: Junta, numa cópia da G01 resolvida, o cabeçalho navegável da F01 e a grelha de categorias da G01. Mantém os atalhos funcionais, testa teclado e rato, e mostra o resultado nas três larguras. Não é uma terceira entrega.
